## Project Overview (from code analysis)

**Name**: Alfabeto Fonético 5x5 (Visual Phonetic Alphabet)
**Type**: Single-file vanilla web application (HTML + CSS + JS)
**Language**: Portuguese (UI, comments, variable names)
**Purpose**: Interactive tool to convert Portuguese text into a custom visual 5x5 grid phonetic notation, and vice-versa (manual drawing with auto-translation).

**Core Concept**:
- Each "block" is a 5x5 grid representing a phonetic syllable/unit.
- **Left column (col 0)**: Vowels (A/E/I/O/U) - sounds before consonant.
- **Center 3x3 (rows 1-3, cols 1-3)**: Consonants with specific mappings.
- **Right column (col 4)**: Vowels - sounds after consonant.
- Cells use states 0-3:
  - 0: empty
  - 1: filled square
  - 2: outlined square
  - 3: outlined square + center dot
- Multiple active cells in one section (left/center/right) receive sequential states (1,2,3) to indicate order/emphasis.

**Letter Mappings** (from `script.js`):
- Vowels: A=0, E=1, I=2, O=3, U=4 (row index)
- Consonants:
  - T/D → (1,1)
  - N → (1,2)
  - M → (1,3)
  - R → (2,1)
  - L → (2,2)
  - J/C → (2,3)
  - K/Q → (3,1)
  - F/V → (3,2)
  - P/B → (3,3)
- S/Z: Special case - empty center block renders as "S"

**Two Operating Modes** (tabbed UI):

1. **Modo Texto (Text Mode)**:
   - Real-time input field.
   - Text normalized (NFD diacritics stripped, uppercased).
   - Automatic conversion to sequence of visual blocks.
   - Handles spaces as block separators.
   - Logic in `processarTexto()` + `renderizarModoTexto()`.
   - Canvas auto-resizes horizontally for long inputs.

2. **Modo Desenho (Draw Mode)**:
   - Manual cell clicking/touching to toggle states.
   - Smart state assignment for new cells (sequential per section).
   - "+" button to add new blocks (horizontal scroll).
   - Optional translation toggle: shows phonetic text below each block using `descodificarBloco()`.
   - Touch support with `touchstart` handler.

**Technical Details**:
- Canvas dimensions: 800x240 base, dynamically widened.
- Constants: CELL_SIZE=25, GAP=4, BLOCK_MARGIN=40, BLOCK_WIDTH=5*25+4*4=129, ADVANCE_X=169.
- No external dependencies, no build step.
- Dark theme (#1a1a1a background).
- Responsive layout with scrollable canvas containers.
- Event handling for both mouse and touch in draw mode.
